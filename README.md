# Edwin Sixtos Ruiz - Portfolio

Personal portfolio website for my cybersecurity, network engineering, homelab, and Purdue CIT coursework.

This site is built with Gatsby and adapted from Brittany Chiang's v4 portfolio design. The original design foundation made this version possible, and attribution is kept in both the website footer and this README.

## About

This portfolio highlights my growth as a Cybersecurity and Network Engineering student at Purdue University Polytechnic Institute. It includes featured technical builds, selected learning highlights, certifications, work experience, and a full Technical Learning Archive that tracks coursework, labs, and independent builds from 2023 through 2026.

## Featured Areas

- Cybersecurity and incident response
- Network engineering and infrastructure
- Active Directory and Windows Server labs
- SIEM monitoring with Wazuh
- Homelab design, VLANs, VPNs, and self-hosting
- Cryptography and secure communication projects
- Purdue CIT coursework and applied learning

## Selected Projects

- [CryptoChat](https://github.com/esixtosr/CryptoChat) - encrypted peer-to-peer messaging project focused on key exchange, authenticated encryption, trust verification, and packet-level validation.
- [12U Bare-Metal Homelab](https://github.com/esixtosr/12U-Bare-Metal-Homelab) - compact rack-based homelab for segmentation, virtualization, infrastructure services, and security testing.
- [NetFlow](https://github.com/esixtosr/NetFlow) - interactive network topology visualization tool for mapping devices, connections, and VLAN environments.
- [3D-Printed TrueNAS Homelab](https://github.com/esixtosr/3D-Printed-TRUENAS) - custom NAS and self-hosting platform used for storage, Jellyfin, backups, and infrastructure experiments.

## Technical Learning Archive

The archive reframes the original project list into a learning timeline. It includes:

- Purdue CIT courses by term
- Smaller coursework and lab artifacts
- Personal builds that should not all appear on the main highlights grid
- Clickable detail panels for context, skills practiced, and lessons learned

This keeps the homepage selective while still showing the full progression behind the portfolio.

## Installation

Install dependencies:

```sh
npm install
```

Start the development server:

```sh
npm run develop
```

The site will usually run at:

```sh
http://localhost:8000
```

## Build

Create a production build:

```sh
npm run build
```

Preview the production build locally:

```sh
npm run serve
```

## Deployment

This repo includes a GitHub Pages deployment script:

```sh
npm run deploy
```
