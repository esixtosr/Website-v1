A Purdue CIT programming course where I moved from basic programming concepts into object-oriented design, collections, exception handling, persistence, and larger software assignments.

### What this was

CNIT 25501 introduced software development concepts common to modern object-oriented languages. The course covered methods, arrays and collections, encapsulation, inheritance, polymorphism, exception handling, data persistence, database connectivity, user interface construction, testing, debugging, and teamwork.

### What I worked on

- Built programming exercises using object-oriented design concepts.
- Practiced working with methods, arrays, collections, and intermediate control structures.
- Studied encapsulation, inheritance, polymorphism, exception handling, and persistence.
- Worked toward more complex assignments that required planning, testing, and debugging.

### What I learned

This course helped me think about software as organized systems instead of isolated scripts. It also gave me a stronger base for later security tooling, automation, and projects that needed cleaner structure.
