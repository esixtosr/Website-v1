A personal wireless security lab using the Hak5 WiFi Pineapple Mark VII to study Wi-Fi attack surfaces, rogue access point behavior, client trust, and defensive awareness in controlled environments.

### What this was

This project used the WiFi Pineapple Mark VII as a learning platform for understanding how wireless networks can be audited, monitored, and misconfigured. I focused on how devices discover and trust networks, how access points and clients appear in the wireless landscape, and why scope control matters during security testing.

### What I worked on

- Explored wireless reconnaissance concepts using access point and client visibility.
- Studied rogue access point and captive portal behavior from a defensive education perspective.
- Practiced thinking through deauthentication risk, network disruption, and why wireless testing must stay controlled and authorized.
- Reviewed how modular tooling and automated campaigns can support repeatable wireless security assessments.

### What I learned

The biggest takeaway was that wireless security is not only about passwords. Client behavior, signal exposure, access point impersonation, network segmentation, and user awareness all affect real-world risk. This lab helped me connect offensive wireless techniques to safer network design, monitoring, and security awareness training.
