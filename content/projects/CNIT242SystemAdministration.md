A foundational Purdue CIT systems administration course where I built hands-on experience with Windows Server, Active Directory, virtualization, storage, backups, and troubleshooting.

### What this was

CNIT 24200 introduced the core systems administration skills behind cybersecurity, networking, IT operations, and infrastructure work. The course focused on managing enterprise-style Windows client and server environments while connecting authentication, authorization, system security, and reliability.

### What I worked on

- Managed users, groups, organizational units, and group policy concepts in Windows Server environments.
- Practiced system administration tasks across virtualization, SSH access, storage planning, backups, and troubleshooting.
- Studied enterprise infrastructure fundamentals, including directory services, authentication, authorization, and system management.
- Connected server administration decisions to reliability, security, and long-term maintainability.

### What I learned

This class became one of the major starting points for my cybersecurity path and teaching assistant work. It gave me the foundation to understand how real environments are built, managed, secured, backed up, and repaired when something goes wrong.
