My first self-directed Active Directory environment, built as a small Windows domain lab to practice domain setup, user management, and enterprise-style administration outside of class.

### What this was

This was an early attempt to recreate system administration concepts on my own. I set up a small Active Directory lab with a domain controller, virtual machines, and test users so I could practice beyond the exact structure of CNIT 242.

### What I worked on

- Built a small Active Directory environment for personal practice.
- Created a domain, test users, and basic identity management structure.
- Used virtualization to experiment without touching production systems.
- Connected classroom system administration concepts to my own repeatable lab setup.

### What I learned

This was one of my first signs that I wanted to go beyond coursework. It helped me understand directory services, user administration, domain structure, and why identity management matters in enterprise environments.
