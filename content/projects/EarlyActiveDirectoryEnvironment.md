My first self-directed Active Directory environment, built as a small Windows domain lab to practice domain setup, user management, and enterprise-style administration outside of class.

### What this was

This was an early attempt to recreate system administration concepts on my own. I set up a small Active Directory environment with multiple domains, a virtual machine, and test users so I could practice beyond the exact structure of CNIT 242.

### What I worked on

- Built a small Active Directory environment for personal practice.
- Created domains and test users to understand basic identity management.
- Used virtualization to experiment without touching production systems.
- Connected classroom system administration concepts to my own lab setup.

### What I learned

This was one of my first signs that I wanted to go beyond coursework. It helped me understand directory services, user administration, and domain structure in a more personal, repeatable lab environment.
