An interactive network topology visualization tool inspired by Cisco Packet Tracer, built to map infrastructure layouts, visualize VLAN segmentation, and document network architectures.

### What this was

NetFlow is a web-based tool for creating devices, defining connections, organizing VLAN environments, and exporting network diagrams for documentation and analysis. It grew out of the need to represent real homelab infrastructure more clearly.

### What I worked on

- Built an interactive topology interface using React and JavaScript.
- Modeled network devices, connections, VLAN environments, and lab infrastructure layouts.
- Published the tool with GitHub Pages for easier viewing and sharing.
- Connected network engineering practice to clearer documentation and visual communication.

### What I learned

This project helped me turn network design into something more understandable and inspectable. It strengthened both my frontend skills and my ability to document technical infrastructure in a way that supports troubleshooting and explanation.
