A Raspberry Pi-based smart mirror prototype from CNIT 17600 where I experimented with small-form-factor computing, camera input, Linux setup, and facial recognition.

### What this was

This project came out of CNIT 17600 Information Technology Architectures, an introductory Purdue CIT course that used Raspberry Pi labs to explore operating systems, networked systems, distributed architectures, and how IT components work together.

### What I worked on

- Set up a Raspberry Pi as the base device for a smart mirror-style prototype.
- Experimented with facial recognition as the main interactive feature.
- Connected hardware setup, operating system configuration, and application behavior into one working project.
- Kept the build afterward as a reminder of my early hands-on work with physical computing.

### What I learned

This was an early technical build, not a major cybersecurity milestone, but it helped me get comfortable with Raspberry Pi hardware, Linux-style setup work, and how software depends on the device, operating system, and architecture underneath it.
