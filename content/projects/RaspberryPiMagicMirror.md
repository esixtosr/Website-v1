A Raspberry Pi-based smart mirror build from CNIT 17600 where I experimented with small-form-factor computing, camera input, and facial recognition in a hands-on hardware environment.

### What this was

This build came out of CNIT 17600 Information Technology Architectures, an introductory Purdue CIT course that used Raspberry Pi labs to explore operating systems, networked systems, distributed architectures, and interoperability between IT components.

### What I worked on

- Set up and worked with a Raspberry Pi as the base device for a smart mirror-style system.
- Experimented with facial recognition as the main interactive feature.
- Practiced connecting hardware, operating system setup, and application behavior into one working prototype.
- Kept the build around afterward as a personal reminder of early hands-on work with physical computing.

### What I learned

This was an early technical build rather than a major cybersecurity milestone, but it helped me get comfortable with Raspberry Pi hardware, Linux-style setup work, and the way software depends on the underlying device, operating system, and architecture choices.
